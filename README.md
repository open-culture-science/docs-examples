# docs-examples

Examples of API and device usage, referenced from [docs.openculture.ai](https://docs.openculture.ai).

## Contents

| Folder | What it is |
|---|---|
| [`experiment-demo/`](experiment-demo/) | Three-script example against the habitat API — prime a media line, run timed media exchanges on a chip, park the rig dry. Meant to be copied onto a Pi and run there. |
| [`co2-sensor/`](co2-sensor/) | Standalone example for reading the CO2/temperature/humidity sensor directly over USB — no habitat server involved. |

Each folder is self-contained: its own `README.md`, its own `requirements.txt`.
